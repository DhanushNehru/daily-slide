# Contributing
Thanks for helping. Small, focused changes are easiest to review.
1. Fork the repo and create a branch from main.
2. Run `node tests/unit.test.js` before you open a PR.
3. Keep the game dependency-free and free of browser storage, ads, links and tracking. The only network request allowed is the required Playables SDK script.
4. Describe what you changed and how you checked it.
Good first issues: new UI languages in `src/strings.js`, more art themes in `src/art.js`, extra tests.
